Image Resize / Crop
Simple resize: choose 50%, 25%, 1200px, 800px, or use Custom Size. Crop still uses crop width and crop height from the center.
Easiest way: choose Make image 50% smaller, then press Resize Images. If you upload only 1 image, it will download as a normal JPG file. If you upload 2 or more, it will download as ZIP.
Image MB Reducer
Try to reduce image size close to a target KB size like 500 KB. Best for making images smaller for upload or sharing.
Example: if your image is 5 MB, type 500, then press Reduce Image Size. If you upload 1 image, it downloads directly. If you upload 2 or more, it downloads as ZIP.
